# 界面设计规范 · THEMES

> 本文由 `tools/gen_theme_doc.py` 从 `ui_theme.py` 自动导出，色值即界面实际使用的值。
> 改色后请重跑：`.venv\Scripts\python.exe tools\gen_theme_doc.py`

共 **5 套主题**，默认 `qiubo`（秋波蓝）。

## 1. 设计原则

1. **单一强调色。** 每套主题只有一个强调色，只出现在主按钮、选中态、滑块、链接与焦点环上；其余全部交给中性灰阶——这是「干净」的来源。
2. **填充式字段，而非描边框。** 输入框 / 下拉用比卡片暗（浅色主题）或亮（暗色主题）一档的底色来区分，描边只作辅助。Gradio 的控件容器默认就靠底色区分，若字段底与卡片底同色，下拉框会直接「消失」。
3. **极轻阴影。** 浅色主题用 `rgb(24 32 32 / 3%)` 加一层大范围低透明投影；暗色主题换纯黑阴影，不靠发光。
4. **统一圆角。** 卡片 16px、字段 10px、按钮 12/10/8px、调色盘按钮 10px。
5. **零网络字体。** 只用系统字体栈，断网也是这个样子。
6. **对比度是硬约束。** 每套主题必须通过 `tools/themecheck.py`：正文 / 底 ≥ 7:1、次要文字 ≥ 4.5:1、三级文字 ≥ 3:1、按钮文字 ≥ 4.5:1。

## 4. 组件样式规范

### 4.1 圆角

| 对象 | 值 |
|---|---|
| 卡片 / 区块容器 | 16px |
| 输入框 / 下拉 | 10px |
| 主按钮 | 12px |
| 次级按钮 | 10px |
| 小按钮 | 8px |
| 调色盘按钮 | 10px |

### 4.2 主按钮

高度 48px、字号 15px、字重 600、字距 0.03em。底色 `primary`，hover `primary_deep`，无边框，阴影从 `0 1px 2px` 抬到 `0 2px 8~10px`。点按时阴影归零，靠位移反馈。

### 4.3 输入字段 / 下拉

底色 `field`，描边 `field_border`（字段底再深 / 亮一档），focus 时描边换成强调色，外加 3px 半透明光晕（浅色 16%、暗色 24% 不透明度）。圆角 10px，无内阴影。

| 主题 | 字段底 | 卡片底 | 通道平均差 |
|---|---|---|---|
| 秋波蓝 | `#EEF2F4` | `#FFFFFF` | Δ13.7 |
| 竹月青 | `#EEF2F1` | `#FFFFFF` | Δ14.7 |
| 桂黄暖 | `#F3F0E9` | `#FFFDFA` | Δ14.0 |
| WorkBuddy 亮 | `#F5F5F7` | `#FFFFFF` | Δ9.3 |
| WorkBuddy 暗 | `#242424` | `#1A1A1A` | Δ10.0 |

### 4.4 卡片

圆角 16px，1px 描边用 `border`，底色 `surface`，阴影 `ts-shadow-card`。卡片内部不再套第二层框，字段直接浮在卡片底上。

### 4.5 主题选择器（调色盘下拉）

页头右侧一个 44×38px 的调色盘图标按钮（`gr.Dropdown` 伪装：选中值文字隐藏，Gradio 自带箭头换成 SVG 调色盘图标，用 CSS `mask` 上色，颜色取当前主题的强调色——换主题时图标颜色跟着变）。点击弹出下拉列表：面板圆角 12px、卡片底 + 描边 + 卡片阴影，选中项用 `soft` 底加粗高亮。选择结果写入项目根目录 `.ui_theme.json`（已 gitignore），**重启 / 刷新后自动恢复**。切换本身由 Python 回调替换 `gr.HTML` 里的 `<style>` 完成，**不依赖任何前端 JS**。

### 4.6 字体

| 用途 | 字体栈 |
|---|---|
| 正文 | `system-ui` → `PingFang SC` → `Microsoft YaHei UI` → `sans-serif` |
| 日志 / 代码 | `Cascadia Mono` → `JetBrains Mono` → `Consolas` → `monospace` |

### 4.7 滚动条

宽 8px，滑块用 `ts-scroll`（浅色主题黑 14%、暗色主题白 16%），悬停加深，轨道透明。

## 5. 派生规则

每套主题只声明约 13 个基准色，其余 100 多个 Gradio 语义变量由 `_variables()` 推导：

| 变量 | 浅色主题 | 暗色主题 |
|---|---|---|
| `primary-50` | `soft` 向白外推 55% | `soft` 向页底外推 55% |
| `primary-200 / 300 / 400` | `soft` → `primary` 插值 24% / 48% / 74% | 同左 |
| `primary-700 ~ 950` | `primary_deep` 向黑外推 14/28/44/60% | 向白外推 |
| `neutral-50 → 950` | 最浅 → 最深 | 最暗 → 最亮 |
| `field` | 页底压暗 3% | 页底提亮 14%，或用主题自带的 `field` |
| `input-border-color` | 字段底压暗 7% | 字段底提亮 12% |
| 卡片阴影 | `rgb(24 32 32 / 3%)` | `rgb(0 0 0 / 55%)` |

## 6. 如何新增一套主题

1. 在 `ui_theme.py` 的 `PALETTES` 里加一项，填全 13 个基准色（`mode` 必填）。
2. 跑 `.venv\Scripts\python.exe tools\themecheck.py`，把不达标的色改到达标为止。
3. 跑 `.venv\Scripts\python.exe tools\uicheck.py` 确认界面能正常构建。
4. 跑 `.venv\Scripts\python.exe tools\gen_theme_doc.py` 刷新本文。
5. 下拉列表会自动多出一项，`app.py` 不用改。
